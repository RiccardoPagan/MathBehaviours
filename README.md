# Math Behaviours

This repository contains materials for a project that aims to examine how math-related attitudes influence students’ performance and behaviours in an adaptive mathematical task.

## What’s Inside

- **Simulated Data** – Datasets generated for analysis.  
- **Data Generation Code** – Scripts to reproduce the datasets.  
- **Analysis Scripts** – R script file for performing analyses.  
- **Hypotheses & Research Questions** – An `.Rmd` file documenting research questions, hypotheses, and the mathematical formulas behind the analyses.

## How to use this repository locally on your pc

1. Open you Terminal (MacOS) or Command Prompt (Windows)
2. Move to your desired directory:
   cd /path/to/your/desired/folder
4. Clone the repository:
   git clone https://github.com/RiccardoPagan/MathBehaviours.git
